## 🔐 Prisijungimo Sistema

### Kaip Veikia Registracija?

1. **Spaudi** "Prisijungti" mygtuką
2. **Įvedi:**
   - 🎭 **Slapyvardis** (3-20 simbolių)
   - 📧 **El. paštas** (teisingas formatas)
   - 🔑 **Slaptažodis** (mažiausia 8 simboliai, raidės + skaičiai)
3. **Spaudi** "Registruotis"
4. ✅ **Iš karto prisijungi!**

### Duomenų Saugumas

- 🔒 **Slaptažodžiai** šifruojami (Base64)
- 💾 **Visi duomenys** saugomi tavo **naršyklėje** (localStorage)
- ❌ **Serveris NĖRA** - jokios aplaudytos duomenys
- 🛡️ **Tavo privatumas** mums svarbiausias!
